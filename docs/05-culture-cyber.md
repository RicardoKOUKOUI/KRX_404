# 05 — Culture cybersécurité

L’aspect offensif n’est qu’**une** branche. Un junior crédible comprend le paysage.

## Domaines à connaître (vue d’ensemble)

- **Blue team** : SOC, détection, réponse à incident
- **Red team / tests autorisés** : simulation d’attaque dans un cadre légal
- **AppSec** : sécuriser le code / le cycle de dev
- **Gouvernance** : politiques, risques, conformité (haut niveau)

## Concepts clés

- CIA : Confidentialité, Intégrité, Disponibilité
- Surface d’attaque
- Authentification vs Autorisation
- Principe du moindre privilège
- Defense in depth

## Lectures / bases

- OWASP Top 10 (à relire souvent)
- Notions CVE / CVSS (sévérité)
- Différence vulnérabilité / exploit / impact métier

## Éthique (non négociable)

- Pas de scan / attaque hors scope
- Pas de “tests” sur le Wi‑Fi du voisin
- Documente toujours ton autorisation
