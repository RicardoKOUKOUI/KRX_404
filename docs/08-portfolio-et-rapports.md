# 08 — Portfolio, rapports & visibilité

En junior, on ne te juge pas seulement sur “j’ai root”.  
On te juge sur : **clarté, méthode, éthique, remédiation**.

## Ce que ton GitHub doit montrer

1. Ce repo (`KRX_404`) = ton chemin
2. Des write-ups labs
3. 1 projet utile (ex. aide au reporting)
4. Un README propre sur ton profil

## Structure d’un finding “pro”

1. Titre
2. Sévérité / CVSS
3. Description
4. Impact
5. Preuve (steps)
6. Remediation
7. Références (OWASP/CWE)

## LinkedIn (honnête)

- “Voici mon parcours et ce que j’apprends”
- Montre une démo réelle
- N’invente pas d’expérience client

## Objectifs junior réalistes

- Stage / assistant pentester / AppSec junior
- Contribuer à des labs / write-ups
- Continuer à publier régulièrement

- [ ] Profil GitHub clair
- [ ] Au moins 1 projet portfolio
